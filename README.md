# Amoreellaa — Վեբ հրավիրատոմսեր

Minimalist Armenian wedding and event invitation landing page built with Next.js.

## Run locally
1. Install Node.js 20.9+.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy
Push this project to a GitHub repository and import it in Vercel. Vercel detects Next.js automatically.
To connect amoreellaa.am after deployment, open the Vercel project Settings → Domains and add the domain. Update DNS records as Vercel instructs.

## Customize
- Main page: `app/page.tsx`
- Styling and colors: `app/globals.css`
- Site title and description: `app/layout.tsx`
- Instagram currently links to `https://www.instagram.com/amoreellaa/`.
